About the project

Built with a hepatologist at the table, not just a dataset.

Dr. A. Bekele — Hepatology Consultant (clinical advisor, illustrative)

LiverAI's model is trained on the Indian Liver Patient Dataset, but the choice of which lab values to ask for, and how results are framed, was shaped alongside hepatology input so the tool reads like something a clinician would actually want to glance at — not a black box.

  • Every input field maps to a real, standard liver-function test — nothing invented.
  • Risk framing (Low / Moderate / High) is deliberately conservative near the decision boundary.
  • The model's reasoning is explainable: each prediction shows which values drove it.

Illustrative profile for this demo — LiverAI is an educational tool, not a certified medical device, and doesn't replace an actual clinical consultation.
